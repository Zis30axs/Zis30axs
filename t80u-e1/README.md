# T-80U-E1 主战坦克 · 交互式三维技术图解

用 Three.js 在浏览器里程序化建模的 T-80U-E1（Т-80УЕ-1）主战坦克。模型不依赖任何外部模型文件，
车体由装甲板拼成、炮塔为放样生成的铸造外壳，车内布置了乘员、转盘式自动装弹机、燃气轮机等模块。

## 功能

| 模式 | 内容 |
| --- | --- |
| 总览 | 整车外观与主要参数；调节炮塔方向、火炮俯仰；X 光透视、三色迷彩、履带行驶动画 |
| 爆炸拆解 | 27 个部件组按先外后内的顺序分离，带引线标注；点选部件查看型号与作用 |
| 装填与击发 | “Korzina”转盘式自动装弹机的完整流程：选弹 → 火炮到装填角并锁定 → 转盘就近转动（26°/s）→ 提升并展开弹匣 → 一次推弹入膛 → 闭锁 → 残底放回空弹匣 → 弹匣降回 → 解锁 → 激光测距 → 电击发 → 出膛慢动作（穿甲弹弹托分离）→ 复进、开闩、抛出残底。可播放、拖动时间轴、逐步查看，支持 5 种弹药切换，转盘俯视图实时显示 28 个弹匣的弹种与余量 |
| 入射分析 | 防护热图按所选弹种和距离实时标出可击穿/临界/无法击穿/可能跳弹的区域；悬停显示入射角、等效防护与判定；点击射击后逐层列出名义厚度、视线厚度、材料系数和等效厚度，并计算“接触-5”反应装甲、破甲射流空气间隙衰减与跳弹概率 |
| 模块损伤 | X 光下按状态给乘员和模块着色；击穿后按弹体路径和破片锥判定损伤，油箱会起火，发射药被引燃会殉爆并把炮塔抛飞；显示整车状态（丧失机动/火力、乘员伤亡等） |

弹药：3BM46“铅-1”、3BM42“芒果”尾翼稳定脱壳穿甲弹，3BK18M 破甲弹，3OF26 杀伤爆破弹，9M119M1“英瓦尔-M”炮射导弹。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生成单文件 dist/index.html（three.js 已内联，可直接双击打开或部署到任意静态托管）
```

操作：左键拖动旋转、滚轮缩放、右键平移（触屏为单指旋转、双指缩放/平移）。
装填与击发模式下，空格键播放/暂停，←/→ 切换步骤。

## 代码结构

```
src/
  core/        app（渲染器、场景、模式切换）、tween、粒子特效、三维标注
  tank/        尺寸、材质、车体、行走装置、炮塔、火炮、自动装弹机、车内布置、弹药模型
  data/        装甲分区与材料系数、弹药参数、模块定义
  features/    总览、爆炸拆解、装填时间轴、弹道计算、防护热图、射击可视化、损伤模型与界面
```

- 装甲按分区定义沿表面法线的分层（如炮塔正面：铸钢 150 + 胞状填充 330 + 铸钢 100 mm），
  射线命中后按 `视线厚度 = 名义厚度 / cos(入射角)`、`等效厚度 = 视线厚度 × 材料系数` 逐层累计。
- 装填流程的每一步只根据进度设定绝对状态，所以时间轴可以任意拖动、回退。

## 说明

T-80U-E1 是 2005 年俄军采用的改进型：以 T-80BV 车体换装退役 T-80UD 的炮塔，加装第二代热像仪、
可装填加长穿甲弹的改进型装弹机、车体“接触-5”反应装甲和 1250 马力 GTD-1250 燃气轮机，产量不足百辆。

装甲厚度、穿深、材料系数、模块耐久与殉爆概率等数值来自公开资料和游戏化估算，并做了大幅简化，
仅用于教学演示，不代表真实性能。
